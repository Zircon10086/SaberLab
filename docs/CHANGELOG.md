### 性能
- **分析计算提速 26.6%（串行 13.4s → 9.8s，单条 33 → 24.2 ms）**（2026-09，第 3 步）：
  1. **`NoteParams.decode` 记忆化 + 解析时一次性预解码**：同一条回放的
     accuracy/scoring/notes/energy 四个阶段各自解码同一批 note，一次完整分析要
     **40531 次**解码（单条大回放实测 1.02ms 纯解码）。现在解析时解码一次存进
     `NoteEvent._params`，热态 0.38ms，属性访问 40531 次归零
  2. **`cut_scores` 记忆化**：scoring 与 note 分组两个阶段都要算它（每条 good/bad
     note 算两遍）。它是纯函数（只依赖 cut 信息与 noteID），缓存在 note 对象上
  3. **`_group_metrics` 单遍计数**：原本每条 note 要经 `_attr()` 做 4 次分类判断
     （一次分析约 4 万次函数调用）；改为 NoteEvent 路径单遍计数，
     **指标表达式与命名逐字不变**
- 数值安全：第 3 步全程以"指标数值不得变化"为红线——12 条回放重算后
  `metrics` 与 `notes` **逐行零差异**（含 energy/fail_time），全量 311 项测试通过；
  全量重算后行数与抽样指标（accuracy/score/fail_time/min_energy/total_drain）与基线一致
- **批量分析提速约 12 倍（246s → 20.4s，全库 416 条）**（2026-09，用户批准方案）：
  1. **数据库写入合并**：`Repository` 改为线程内**复用同一连接**，并把一次分析的
     全部写操作包进**单个事务**（`Repository.session()`）。此前每条回放开 4 个连接、
     4 次独立提交；实测新连接 18.7ms/次 vs 复用 2.2ms/次。单条落库
     **59.3ms → 9.5ms**，且一条回放的数据现在是**原子写入**（失败整体回滚，不再半写）
  2. **消除重复的地图库全量重扫**：`resolve()` 在 DB 未命中时会触发 CustomLevels
     全量扫描（本机 1032 个谱面目录，**单次 13.8 秒**）。批量里每条未匹配的回放都会
     请求一次，4 个 worker 进程还会各扫一遍——**这才是真正的大头**。现在批量路径
     **前置扫描一次**、worker 内部不再触发重扫（`map_scan=False`）；交互式单文件分析
     保留重扫，新下载的谱面照常识别
  3. **批量分析改 4 进程并行**：线程无效（实测 1.04–1.24x，热点是 GIL 绑定的 Python
     循环），进程实测 **1.95x**（其余收益全部来自前两项）
- **批量分析跳过源文件已缺失的回放**：DB 行比文件长寿（ingest 只增不删），此前每次
  批量都会对这些回放产生一遍"文件不存在"的错误结果

- **失败时间（fail time）本地计算**（2026-09）：`.bsor` 的 `failTime` 字段**从未被
  mod 写入**（本机 498/498 个回放恒为 0），因此按**反编译得到的官方算法**
  （`GameEnergyCounter`）在本地重算能量曲线与失败时刻。官方常数（三版本
  1.39.0/1.40.8/1.44.1 完全一致）：good 音符 +0.01 / bad −0.10 / miss −0.15 /
  切炸弹 −0.15 / burst 滑块元素 +0.002 / −0.025 / −0.03 / 障碍物 −1.3 每秒；Bar 模式
  起始 0.5、Battery 与 instaFail 起始 1.0（4 格电）、上限 1.0；能量 ≤1e-5 即失败。
  实现为 `backend/analysis/energy.py`（确定性纯函数，无网络无 LLM）。
  **呈现**：详情页时间轴卡片下方新增能量小结（最低能量 / 失败时间 / 扣血来源分解 /
  撞墙次数），时间轴启用**失败时间红轴**标记（像素级校验：轴刻度映射偏差 0.04px）。
  **fail 时间与完成度分类刻意分离**——fail 后坚持打完、fail 前主动退出、fail 后退出
  都按事实呈现，不猜测玩家意图。**顺带产出**多项衍生遥测（能量事件流可重放、
  分来源扣血、分手充能、障碍物检查点、危险区时长等），全部落 `metrics` 表的
  `energy` 段，既有读取路径即可取用，**不新增表**
- **批量重算开关**：`POST /api/analyze/all?force=true` 可无视 `analysis_status`
  重算全部回放——引擎新增指标后回填历史数据用，避免为几个数字清空整个分析缓存
- **总览新增「按游玩段」分页**（2026-09，用户需求）：按**相邻两次 Replay 的时间

  文案「共 N 个游玩段 / 上一段 / 下一段」（三语言）。**该项排在标签最左并作为
  默认选中**（原「按天」退居第二，仍可选择；「按数量」不变）。**段标题始终带年月日**
  （单日段显示 `2026-09-03 18:49 – 19:50`，跨天段两端都带日期显示
  `2026-09-07 23:24 – 2026-09-08 00:03`）——只给时刻的话玩家看不出是哪一天玩的
- **侧栏玩家卡片**：左下角（「服务器运行中」上方）显示当前玩家——头像、名称、

### 变更
- **AI 密钥只从本地配置文件读取**（2026-09，用户决定）：以前密钥还会读系统环境变量——
  若你的机器上为别的工具设过 `DEEPSEEK_API_KEY`，一个从未配置过的 SaberLab 也会显示
  「已配置」并拿它去请求服务。现在**只读程序目录里的 `.env`**，环境变量不再有任何影响；
  在设置里保存密钥立即生效，来源固定标注为「本地配置文件」
- **玩家能力预估改为三档基准（80% / 94% / 96%）**（2026-09，用户需求）：星级色谱不再由
  「最高 PP 或平均星级」推一个黄色基准，而是回答"这位玩家在某档准度下能稳定打到多少星"：
  **80% 基准**看能打过的高难图、**94% 基准**看常规水平、**96% 基准**看高准度水平。
  设置 → 星级色谱里可以直接选任一基准，用于列表与详情页 STARS 数字的配色；
  三个基准分别记为 `personal80` / `personal94` / `personal96`，为将来引入其他目标准度留出位置。
  **数据不足的基准不给数值、也不能选**：设置项里置灰并标注「数据不足」，云端数据页
  对应档位同样只写「数据不足」；某档只有经验证据的下界时明确标注「已展示 N★」，
  不把未验证的区间当成精确能力值
- **离开 3D 回放页时暂停播放**（2026-09，用户需求）：详情页的「数据一览 / AI 分析 /
  查看回放」是靠位移切换的同一张页，之前切走后 3D 回放仍在后台继续播放（音频与画面
  都不停），只有打开另一条回放才会重置。现在离开回放页即暂停，播放位置保留；
  **回到回放页不会自动继续**，在回放里点一次播放即可从原位置接着看
- **设置项改为「焦点离开即自动保存」**（2026-09，用户需求）：改完某项、焦点离开
  （Tab / 点别处）即自动保存；下拉与勾选框在值变更时立即保存。保存成功以
  **toast** 反馈，原底部「保存全部设置」按钮与旁边的保存提示文字**已移除**。
  复用同一条保存路径（`collectSettings()` 只提交真实变更的字段），因此不需要
  "保存单项"逻辑；无变更时静默跳过（点空白不会弹提示）。
- **游玩段阈值设置改名 `analysis.session_gap_minutes` → `ui.session_gap_minutes`**
  （2026-09 修复）：它只是总览「按游玩段」的分组阈值、不参与任何分析计算，但落在
  `analysis.*` 命名空间里会被"分析参数变更即清缓存"规则命中——**调整一次就会清空
  全库分析数据**（metrics/motion_series 清空、全部 Replay 转 pending）。现移到
  `ui.*`（设置页「界面」分组），并带一次性迁移：读取旧配置时把旧键搬到新分组、
  从文件里删除，避免同名键残留在两处
- **设置页枚举下拉改为毛玻璃风格**（2026-09，用户需求）：原生 `<select>` 的展开
  列表由操作系统绘制、页面无法改其外观，故改为「毛玻璃触发按钮 + 复用 PP 预测的
  通用锚定弹出组件 `openPopover`」——同一套材质
  （`rgba(20,22,30,0.66)` + `blur(14px) saturate(150%)`）、同一套出入场动画
  （`popIn`/`popOut`）、同样的锚定行为（空间不足自动上翻、左右夹边）与关闭方式
  （点击外部 / Escape / 滚动 / 缩放）。值仍存放在隐藏 `input[data-key]` 上，
  **保存与脏值检测链路零改动**。覆盖设置页全部枚举项（星级色谱、数据源、AI 供应商等）。
  顺带补了自定义下拉应有的 ARIA（`aria-haspopup/expanded`、`role=listbox/option`）。
  **同一点再次点击 = 收起**（不重播入场动画，与 PP 预测弹窗的开关语义一致）
